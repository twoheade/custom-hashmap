# HashMap

Учебный проект в рамках которого я реализовал собственную HashMap на Java, которая хранит пары ключ-значение.
## Что реализовано

- Добавление и обновление элементов (`put`).
- Поиск значения по ключу (`get`).
- Удаление элементов (`remove`).
- Подсчёт количества элементов (`size`).
- Проверка на пустоту (`isEmpty`).
- Обработка коллизий с помощью связных списков.
- Автоматическое увеличение размера массива при заполнении.
- Поддержка `null` в качестве ключа.
